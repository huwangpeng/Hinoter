# 无界笔记（PENKITINFENG）文件格式逆向分析报告

> 分析日期：2026-07-25
> 分析样本：`sample/无边.hinote`
> 分析工具：`tools/analyze_infinite.py`, `tools/analyze_binary.py`

## 一、文件存储格式与目录结构

`.hinote` 文件是标准 ZIP 容器，无界笔记使用与有界笔记相同的容器结构，但内部布局显著不同。

### 完整文件清单

```
无边.hinote (62,893 字节)
├── uuid.jhinote       1,289 B   笔记级元数据 (GZIP+JSON)
├── custom_md.jhinote                                 712 B   文件完整性哈希 (GZIP+JSON)
├── pages/
│   ├── uuid.jhinote     页面 1 元数据 (GZIP+JSON)
│   ├── ...
│   └── uuid.jhinote     页面 n 元数据 → bsd_0_0
└── files/
    ├── bsd_-1_-1_1783950692675556.bin            13,576 B   网格 (-1,-1) 笔迹数据 (PENKITINFENG)
    ├── bsd_-1_0_1784000759752127.bin             34,576 B   网格 (-1,0) 笔迹数据 (PENKITINFENG)
    ├── bsd_0_0_1784423201463245.bin               4,196 B   网格 (0,0) 笔迹数据 (PENKITINFENG)
    ├── gsd_1784423201463245.bin                     128 B   全局状态数据 (Global Stroke Data)
    ├── ged_1784423201463245.bin                      44 B   全局元素数据 (Global Element Data)
    ├── 4a19334c67974e40aa3de7101923a108.png       44,605 B   缩略图 (1024×1024 PNG)
    └── 2d745a294abe4aeb8000493aae6c0bf8_1784423201582_navigation.json
                                                    139 B   导航位置记录 (JSON)
```

### 目录结构说明

| 路径模式 | 文件类型 | 用途 |
|----------|----------|------|
| `{noteId}.jhinote` | GZIP+JSON | 笔记级元数据，包含附件清单和无限画布标志 |
| `custom_md.jhinote` | GZIP+JSON | 文件 SHA-256 哈希校验清单 |
| `pages/{uuid}.jhinote` | GZIP+JSON | 页面级元数据，每个 bsd 块独立一页 |
| `files/bsd_{X}_{Y}_{ts}.bin` | 二进制 | **PENKITINFENG** — 网格坐标 (X,Y) 的笔迹分块 |
| `files/gsd_{ts}.bin` | 二进制 | 2500 单位网格与 BSD 块 ID 的映射 |
| `files/ged_{ts}.bin` | 二进制 | 全局元素元数据 |
| `files/{uuid}.png` | PNG | 当前视图缩略图 (1024×1024) |
| `files/*_navigation.json` | JSON | 导航历史位置列表 |
| `files/*_outline.json` | JSON | 大纲/目录数据 |

## 二、关键数据文件分析

### 2.1 笔记级元数据 `{noteId}.jhinote`

**关键标志**：`data1.isInfNote = "1"` 标识这是一个无限画布笔记。

```json
{
  "customNoteContent": {
    "attachment": [
      { "attachType": 11, "filePath": "..._navigation.json" },
      { "attachType": 12, "filePath": "...gsd_*.bin" },
      { "attachType": 12, "filePath": "...ged_*.bin" }
    ],
    "background": "base6",
    "data1": "{\"isInfNote\":\"1\",\"infStylusPath\":\"...\"}"
  }
}
```

| 字段 | 值 | 说明 |
|------|-----|------|
| `attachType: 11` | navigation | 导航位置记录 |
| `attachType: 12` | gsd/ged | 全局状态数据文件 |
| `isInfNote: 1` | bool | **无界笔记标志** |
| `background` | `"base6"` | 背景模板（点阵） |

### 2.2 页面级元数据 `pages/{uuid}.jhinote`

无界笔记中**每个 bsd 块对应一页**。页码可以跳跃（1, 2, 3, 6），缺失的页码表示该网格无笔迹。

| 字段 | 页面 1 | 页面 2 | 页面 3 | 页面 6 |
|------|--------|--------|--------|--------|
| `pageNumber` | 1 | 2 | 3 | 6 |
| `pageOrientation` | 1 (横向) | 0 | 0 | 0 |
| `pageRatio` | 0.625 | 1.0 | 1.0 | 1.0 |
| `background` | `"base6"` | `""` | `""` | `""` |
| `lastPageTag` | 1 | 0 | 0 | 0 |
| `bkgAttachmentId` | `""` | `""` | `""` | `""` |
| `pageElement` | `[]` | `[]` | `[]` | `[]` |
| `attachment[].attachType` | 无 | **13** → bsd_-1_-1 | **13** → bsd_-1_0 | **13** → bsd_0_0 |

**关键发现**：
- 页面 1 是**主页面**，含 `thumbnail_area`（当前视口位置）和缩略图 PNG
- 页面 2/3/6 各绑定一个 bsd 笔迹块，`attachType=13`
- `pageColor=0`（黑色背景）用于笔迹页面，`pageColor=-1`（白色）用于主页面
- `lastPageTag=1` 标记最后访问的页面

### 2.3 导航数据 `*_navigation.json`

```json
{
  "positions": [
    { "x": -84,   "y": 2 },
    { "x": -155.5, "y": 637.3 },
    { "x": 541.2,  "y": 1638.7 }
  ],
  "curIndex": 2
}
```

| 字段 | 说明 |
|------|------|
| `positions[]` | 用户访问过的画布视口位置（x, y 为画布坐标） |
| `curIndex` | 当前所在位置的索引 (2 表示第三个位置) |

**与 page 1 的关联**：`curIndex=2` 的坐标 (541.2, 1638.7) 与页面 1 的 `thumbnail_area.centerX/centerY` (541.21, 1638.71) **完全一致**。

### 2.4 `thumbnail_area`（来自页面 1 的 `data1` 字段）

```json
{"centerX":541.21, "centerY":1638.71, "scalingFactor":1.5657}
```

| 字段 | 值 | 说明 |
|------|-----|------|
| `centerX` | 541.21 | 当前视口在画布上的中心 X 坐标 |
| `centerY` | 1638.71 | 当前视口在画布上的中心 Y 坐标 |
| `scalingFactor` | 1.5657 | 视图缩放因子 |

## 三、编码方式与序列化格式

### 3.1 元数据文件
- **编码**：全部为 Big-Endian
- **压缩**：`.jhinote` 文件使用 GZIP + UTF-8 JSON
- **`.json` 文件**：纯文本 JSON（无压缩）
- **`.png`**：标准 PNG 图像（1024×1024 像素）

### 3.2 BSD 文件头

BSD、GSD、GED 都以 `PENKITINFENG` 开头，但头部长度和后续结构并不相同。BSD 的固定文件头是 52 字节：

```
偏移    大小    字段名        说明
─────  ─────  ───────────  ───────────────────────────
0      12     magic        "PENKITINFENG" (ASCII)
12      4     block_type   块类型标识 (0x01=bsd, 0x03=gsd, 0x04=ged)
16      4     flags        标志位 (常见 0x00010000)
20      8     block_id     块 ID，与 GSD 记录对应
28      4     field_28     样本恒为 16
32      4     field_32     样本恒为 8
36      4     data_length  文件长度减 52
40      4     field_40     样本恒为 0
44      4     stroke_count 本块笔画数
48      4     field_48     样本恒为 0
─────────────────────────────────────────────
52      —     第一笔的描述数据
```

### 3.3 点表格式（bsd 块）

每笔都可以按下面的结构顺序读取，不需要在整个文件中搜索点表标记：

```text
48 字节笔画描述
12 字节点表头
28 字节笔画元数据
1 字节前缀（0x01）
count × 28 字节点记录
16 字节收尾参数
```

三个样本块都满足：

```text
文件长度 = 52 + Σ(48 + 12 + 28 + 1 + count×28 + 16)
```

点表头：

```
点表头部 (12 字节):
  [0:4]   count      (BE uint32)  — 本笔点数
  [4:8]   stride     (BE uint32)  — 固定为 28 (PENKIT_POINT_STRIDE)
  [8:12]  reserved   (BE uint32)  — 必须为 0

笔画元数据 (28 字节):
  [0:4]   last_index (BE float)   — count - 1
  [4:20]  bbox        (4×BE float)
  [20:24] sequence    (BE uint32) — 含义待确认
  [24:28] sentinel    0xffffffff

第一条点记录 (28 字节):
  [0:4]   pen_type    (BE uint32) — 样本为 1
  [4:8]   base_width  (BE float)  — 样本为 10
  [8:12]  color       (ARGB)      — 样本为 ff000000
  [12:16] opacity     (BE float)  — 样本为 1
  [16:20] x           (BE float)
  [20:24] y           (BE float)
  [24:28] elapsed_ms  (BE uint32)

后续点记录 (28 字节):
  [0:4]   pressure    (BE float)
  [4:8]   field_04    (BE float)  — 样本恒为 0.2
  [8:16]  reserved    样本为 0
  [16:20] x           (BE float)
  [20:24] y           (BE float)
  [24:28] elapsed_ms  (BE uint32)
```

注意：点数据前面的 1 字节前缀会让记录看起来没有按 4 字节对齐。旧版解析器按 4 字节步进，再用 Little-Endian 分支补漏，会漏笔并误读时间字段。

**验证数据**：

| 块 | 表数量 | 每表点数 | stride |
|----|--------|---------|--------|
| bsd_-1_-1 | 16 | 44 / 38 / 24 / 55 / 15 / ... | 28 |
| bsd_-1_0 | 16 | 68 / 47 / 45 / 46 / 179 / ... | 28 |
| bsd_0_0 | 4 | 9 / 8 / 69 / 47 | 28 |

### 3.4 GSD 网格索引

样本中的 GSD 长 128 字节。64 字节头部之后有 3 条 16 字节记录，文件末尾另有 16 字节待确认数据。偏移 44 是 BE float `2500.0`，即网格边长；偏移 56 是记录区长度 48，偏移 60 是记录数 3。

```text
每条记录：
  [0:4]   grid_x       (BE int32)
  [4:8]   grid_y       (BE int32)
  [8:16]  block_id     与 BSD 头部的 block_id 对应
```

样本映射为 `(-1,-1)`、`(-1,0)`、`(0,0)` 三格。点坐标已经是全局绝对坐标，不能再叠加 `grid × 2500`；网格更像是按落笔首点确定的归属索引，一笔可以在书写过程中跨格。

### 3.5 GED

样本 GED 只有 44 字节，块类型为 4。除 magic、flags 和块 ID 外，其余字段含义尚未确认。它显然不具备此前假定的“100 字节通用头”。

## 四、文件关联关系与数据组织

### 4.1 数据流向图

```
{noteId}.jhinote                    ← 笔记入口
├── attachment[]                    ← 附件清单索引
│   ├── attachType=11 → navigation.json  ← 导航历史
│   └── attachType=12 → gsd*.bin         ← 全局笔迹样式
│   └── attachType=12 → ged*.bin         ← 全局元素状态
│
├── data1.isInfNote="1"             ← 无界笔记标记
│
pages/{page_uuid}.jhinote           ← 页面元数据
├── page 1 (lastPageTag=1)          ← 主页面
│   ├── thumbnail → *.png           ← 缩略图
│   └── data1.thumbnail_area        ← 当前视口位置 + 缩放
│
├── page 2 → attachment[].attachType=13 → bsd_-1_-1_.bin
├── page 3 → attachment[].attachType=13 → bsd_-1_0_.bin
├── page 6 → attachment[].attachType=13 → bsd_0_0_.bin

custom_md.jhinote                    ← 完整性校验
  └── SHA-256(文件内容 + 文件名)
```

### 4.2 数据组织规则

| 规则 | 说明 |
|------|------|
| **一页一块** | 每个有笔迹的网格块独立为一页，页码可跳跃 |
| **主页面** | `lastPageTag=1` 的页面记录当前视图状态 |
| **网格坐标编码** | 文件名 `bsd_{X}_{Y}_{timestamp}` 编码块位置 |
| **时间戳标识** | 文件名中的 Unix 毫秒时间戳区分版本 |
| **全局状态共享** | gsd 文件被所有 bsd 块共享 |

### 4.3 网格坐标系统

```
    Grid X,Y 布局（样本数据）:
    
           X=-1       X=0
    Y=0  [bsd_-1_0]  [bsd_0_0]    ← 主要笔迹区域
    Y=-1 [bsd_-1_-1]               ← 上方笔迹
    
    文件名解析: bsd_{grid_x}_{grid_y}_{unix_timestamp}.bin
    范围: grid_x, grid_y 为整数（可为负）
```

### 4.4 关键差异：有界 vs 无界

| 维度 | 有界笔记 (PENCILENGINE) | 无界笔记 (PENKITINFENG) |
|------|------------------------|------------------------|
| 画布 | 固定尺寸页面 | 无限网格画布 |
| 笔迹 | 一页多个 `.bin` 文件 | 每个网格块一个 `.bin` 文件 |
| 文件头 | 76 字节 | **52 字节 BSD 头 + 逐笔结构** |
| 点步长 | 36 字节 | **28 字节** |
| 点格式 | [r, x, y, r, p, ...] | [pressure, ..., x, y, elapsed] |
| 坐标 | 0..1000 页面坐标 | 画布绝对坐标（可为负） |
| 页面 | 页码连续 | 页码可跳跃 |
| 背景 | `bkgAttachmentId` | 无（纯画布背景） |
| 视图 | 固定 | `thumbnail_area` + 导航记录 |
| 标识 | 无 | `data1.isInfNote=1` |

## 六、未解问题

1. **笔画描述和收尾参数**：每笔前 48 字节与末尾 16 字节还有字段未命名
2. **GED 结构**：元素数据的具体用途仍需更多样本
3. **样式验证**：当前样本只有宽度 10 的黑色普通笔，需要彩色笔、荧光笔和不同笔宽样本
4. **分块策略**：现有证据支持按落笔首点归属网格，但仍需边界控制样本确认
